# 系統管理

全站 12 個頁面使用 Vue 3 與 Element Plus，包含首頁、交易紀錄與明細、商品、標籤、統計、對帳單及五個系統管理頁面。導覽、麵包屑、按鈕、輸入、選單、勾選、開關、日期時間、表格、分頁、標籤、提示及對話框皆由共用元件層呈現，使用繁體中文語系。

## 啟動

首次執行 npm ci，再執行 npm start，開啟 http://127.0.0.1:4173/users.html 。需要 Node.js 22 或更新版本，按 Ctrl+C 停止本機伺服器。啟動會自動使用 esbuild 建置 Vue／Element Plus；修改 ui 目錄後執行 npm run build 並重新整理頁面。套件、樣式及字型均由本機提供，不依賴外部 CDN。

## 權限與操作

- 支付工具設定僅系統管理員可存取與修改。每個工具設定一次，全部商店及專案共用同一份設定，不提供商店／專案覆寫或重複設定。一般角色不能藉由權限勾選取得支付工具設定權限。
- 系統管理員可以新增及編輯共用或商店專用角色。功能動作支援整組、部分及個別選取。
- 首頁開放所有角色，不列入權限表。其餘功能依側邊選單列出；新增與編輯共用「新增 / 編輯」選項，檢視、刪除、退款、封存與匯出依功能分別設定。舊角色只要原有新增或編輯任一權限，即轉為合併權限。支付工具設定維持系統管理員專屬。切換商店保留已勾選項目，但不會儲存超出操作者可授予範圍的權限。
- 共用 Vue 介面依目前商店的專案授權過濾選單、頁面及操作入口；直接開啟未授權頁面顯示無存取權限。這些為本機示範的介面控管，正式服務仍需在後端依資料所屬專案驗證每次操作。舊角色的新增權限只遷移一次，之後取消的權限不會因重新載入而恢復。
- 使用者管理支援建立新帳號、加入既有帳號及逐專案指定角色，新增與編輯權限分開判斷。其他商店及未勾選的既有授權保留。
- 商店與專案列表提供搜尋、分頁及關聯檢視；系統管理員可透過 modal 新增／編輯基本資料。專案建立後維持原所屬商店，以保留既有授權範圍。
- 專案與商店共用費率版本列表、起訖時間、狀態、歷程及鎖定規則。專案各支付工具預設「繼承商店」，繼承的費率與啟用狀態隨商店有效設定連動，也可切換為專案自訂。沒有有效專案版本時沿用商店設定；商店亦無有效設定時使用系統設定。
- 商店與專案頁的商店選單為搜尋條件：系統管理員預設全部商店，其他角色預設進入時的商店，全部選項仍只涵蓋授權資料。清除會恢復各角色的預設搜尋範圍。

## 資料與實作範圍

目前資料儲存在瀏覽器 localStorage，使用 payment-system-management-v2。舊版資料會轉移並保留已建立的角色及使用者授權；信用卡保留系統層級費率，舊商店／專案覆寫值不再使用。全部工具由全平台設定集中管理，新加入的商店與專案也直接共用。登入認證與外部帳號、金流等服務尚未串接。

目前帳號由資料中的 currentUserId 提供，未提供前端切換入口。初始帳號為系統管理員；正式認證整合時應由登入工作階段提供身分並在服務端檢查權限。

元件遷移採相容層：ui/element-app.js 讀取既有控制程式的 DOM 狀態，將它轉成真正的 Element Plus 元件，並將操作回傳原控制程式。原 DOM 移入隱藏且排除輔助技術的 controller-source，供既有 FormData、驗證、事件與物件參照使用；畫面僅顯示 Vue 介面。舊樣式表不參與可見介面的樣式。這一層保留原有業務邏輯與儲存格式，後續可按功能逐步改成 Vue 狀態模型，新增介面應直接使用 Vue／Element Plus。

靜態頁原本未串接的查詢或外部金流仍維持原有功能範圍；元件遷移不會新增後端服務或補造未載入的資料。

## 驗證

安裝測試套件：npm ci。安裝測試瀏覽器：npx playwright install chromium。

npm test 驗證權限、資料隔離、資料遷移與各頁共用介面入口；npm run test:browser 會先建置，再執行 tests/element-ui.spec.js，驗證所有路由的桌面／手機載入、搜尋、分頁、角色、使用者授權、支付工具、標籤、商品、付款連結、對帳單封存與報表匯出、退款與發票流程。

其餘舊版 *.spec.js 使用原生 select／dialog 與舊 DOM 選擇器，保留作為遷移參考，不列入新版瀏覽器測試入口。新版測試操作實際可見的 Element Plus 元件。歷史 HTML 雜湊不再作為全站外觀不變的驗收條件。

介面入口：ui/element-app.js、ui/element-app.css；建置：build-ui.js；資料與權限：system-model.js；既有功能控制程式維持原檔案。ui/dist 為建置輸出，不納入版本管理。
