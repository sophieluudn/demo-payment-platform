# 系統管理

目前包含使用者、角色、商店、專案與支付工具設定。沿用原有頁首、側欄及表格版面；其他功能頁與共享 style.css 保持原檔案。

## 啟動

執行 npm start，開啟 http://127.0.0.1:4173/users.html 。需要 Node.js 22 或更新版本，按 Ctrl+C 停止本機伺服器。

## 權限與操作

- 支付工具設定僅系統管理員可存取與修改。每個工具設定一次，全部商店及專案共用同一份設定，不提供商店／專案覆寫或重複設定。一般角色不能藉由權限勾選取得支付工具設定權限。
- 系統管理員可以新增及編輯共用或商店專用角色。功能動作支援整組、部分及個別選取。
- 使用者管理支援建立新帳號、加入既有帳號及逐專案指定角色，新增與編輯權限分開判斷。其他商店及未勾選的既有授權保留。
- 商店與專案列表提供搜尋、分頁及關聯檢視。尚未定義的新增與編輯動作保持停用。
- 畫面保留商店切換；不提供身分切換、測試資料重置或展示說明。

## 資料與實作範圍

目前資料儲存在瀏覽器 localStorage，使用 payment-system-management-v2。舊版資料會轉移並保留已建立的角色及使用者授權；信用卡保留系統層級費率，舊商店／專案覆寫值不再使用。全部工具由全平台設定集中管理，新加入的商店與專案也直接共用。登入認證與外部帳號、金流等服務尚未串接。

目前帳號由資料中的 currentUserId 提供，未提供前端切換入口。初始帳號為系統管理員；正式認證整合時應由登入工作階段提供身分並在服務端檢查權限。

## 驗證

安裝測試套件：npm ci。安裝測試瀏覽器：npx playwright install chromium。

npm test 驗證權限、資料隔離及既有介面保留；npm run test:browser 驗證頁面操作、一般帳號拒絕存取、舊資料轉移與畫面中的測試工具移除。

程式檔案：system-model.js、system-admin.js、system-admin.css、server.js。
